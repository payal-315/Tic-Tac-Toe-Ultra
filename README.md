# Tic-Tac-Toe Ultra

A browser-ready version of the original Java Swing Tic-Tac-Toe game, prepared for Vercel deployment.

## Run Locally

Open `index.html` in a browser.

## Deploy To Vercel

1. Push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Use the default static site settings.

The original desktop Java source is kept in `tic_tac_toe.java`.
